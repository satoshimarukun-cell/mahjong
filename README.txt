雀譜 PWA版

【重要】
PWAとしてホーム画面に追加するには、Safariで http:// または https:// のURLから開く必要があります。
index.html をファイルとして直接開く file:// 方式では、Service Worker とオフライン機能は有効になりません。

【おすすめ】
GitHub Pages などの静的ホスティングに、このフォルダ内のファイルをそのままアップロードしてください。

【iPhone / iPad】
1. Safariで公開URLを開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」
4. 「追加」
→ ホーム画面の「雀譜」アイコンからアプリ風に起動できます。

【Mac】
Safariで公開URLを開き、
「ファイル」→「Dockに追加」
またはSafariのWebアプリ追加機能を利用できます。

成績データはブラウザの localStorage に保存されます。
CSV出力で定期的にバックアップすることをおすすめします。
